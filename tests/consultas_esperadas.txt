SISTEMA DISTRIBUIDO DE ESTUDIOS MEDICOS
Consultas de validacion y resultados esperados
================================================

Ejecutar desde la raiz del proyecto:

  docker exec -it medical_pg psql -U postgres -d medical_oltp

Los conteos corresponden al dataset base, antes y despues de demo.ps1
(la demo limpia sus propios datos).


A. FRAGMENTACION HORIZONTAL
---------------------------

A.1 Pacientes por region
SELECT region, count(*) AS pacientes
FROM operativo.v_pacientes_todos
GROUP BY region
ORDER BY region;

Esperado:
  alajuela | 5
  cartago  | 5
  san_jose | 5

A.2 Total de pacientes
SELECT count(*) FROM operativo.v_pacientes_todos;
Esperado: 15

A.3 Estudios por region
SELECT region, count(*) AS estudios
FROM operativo.v_estudios_todos
GROUP BY region
ORDER BY region;

Esperado:
  alajuela | 5
  cartago  | 5
  san_jose | 5

A.4 Rangos de identificadores
SELECT 'san_jose' AS region, min(id_paciente), max(id_paciente) FROM san_jose.pacientes
UNION ALL
SELECT 'alajuela', min(id_paciente), max(id_paciente) FROM alajuela.pacientes
UNION ALL
SELECT 'cartago',  min(id_paciente), max(id_paciente) FROM cartago.pacientes;

Esperado:
  san_jose | 10001 | 10005
  alajuela | 20001 | 20005
  cartago  | 30001 | 30005

E. SEGURIDAD Y ROLES
--------------------

E.1 Roles existentes
SELECT rolname, rolcanlogin, rolsuper
FROM pg_roles
WHERE rolname IN (
  'usr_fdw_pg_mssql',
  'usr_fdw_pg_mongo',
  'usr_api_web',
  'usr_api_mobile'
)
ORDER BY rolname;

Esperado: 4 filas, todas con rolcanlogin = t y rolsuper = f.

E.2 API web autenticada (desde el host)
  $env:PGPASSWORD = "ApiWeb_2026!"
  psql -h 127.0.0.1 -p 55432 -U usr_api_web -d medical_oltp `
    -c "SELECT count(*) FROM api_web.v_paciente_facturacion;"
Esperado: 15

E.3 API movil autenticada
  $env:PGPASSWORD = "ApiMobile_2026!"
  psql -h 127.0.0.1 -p 55432 -U usr_api_mobile -d medical_oltp `
    -c "SELECT count(*) FROM api_mobile.v_paciente_resumen;"
Esperado: 15

E.4 API web no puede leer tablas internas
  psql -h 127.0.0.1 -p 55432 -U usr_api_web -d medical_oltp `
    -c "SELECT count(*) FROM operativo.v_pacientes_todos;"
Esperado: ERROR: permission denied for schema operativo

E.5 API web solo ve sus vistas
SELECT grantee, table_schema, table_name, privilege_type
FROM information_schema.role_table_grants
WHERE grantee IN ('usr_api_web', 'usr_api_mobile')
ORDER BY grantee, table_schema, table_name;

Esperado: 5 filas (3 de api_web y 2 de api_mobile), solo SELECT.

G. PRUEBA DE FALLO (OPCIONAL, MANUAL)
-------------------------------------

1. docker stop medical_mongo
2. SELECT operativo.sp_registrar_estudio(
       'san_jose', 10001, 3, 501,
       jsonb_build_object('hallazgo', 'Prueba de fallo'),
       'R10.4', 'Prueba de outbox');
3. Verificar outbox PENDIENTE.
4. docker start medical_mongo
5. SELECT operativo.sp_reintentar_outbox();
6. Verificar outbox SINCRONIZADO.
7. Limpiar el estudio de prueba para no alterar los conteos.
